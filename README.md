# Daymark To-do List

A simple, responsive to-do list web app that keeps your tasks saved in your browser.

## Run it

Open `index.html` in a modern browser. No dependencies, build step, or server are required.

## Features

- Add, complete, reopen, and delete tasks
- Filter tasks by all, active, or completed
- See your completion progress at a glance
- Keep tasks between visits with browser local storage
- Responsive layout and keyboard-accessible controls
