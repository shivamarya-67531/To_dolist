## 🚀 Get started

No setup needed:

1. Download or clone this repository.
2. Open **[`index.html`](./index.html)** in a modern browser.
3. Add your first task and take it one step at a time.

> **Your tasks stay on your device.** Daymark uses your browser’s local storage; it does not sync tasks between devices.

## 🧭 How to use it

1. Type a task in the field and select **Add task** (or press Enter).
2. Select the circle beside a task to mark it done. Select it again to reopen it.
3. Use **All**, **Active**, and **Completed** to filter the list.
4. Use the trash icon to remove one task, or **Clear completed** to tidy up.

The progress card updates as you complete tasks. A fresh list starts at 0%; finishing every task brings it to 100%.

## 🔒 Privacy & storage

Your tasks are stored locally in your browser under the key `daymark-tasks-v1`. Clearing browser site data removes the saved list. Opening the app in a different browser or on another device starts a separate list.
